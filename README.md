# English Learning Telegram Bot

Асинхронный Telegram ИИ-помощник для изучения английского языка. Ассистент работает в гибридном режиме (текст и аудио).

## Архитектура и стек технологий

- **Фреймворк:** aiogram 3.x (полная асинхронность).
- **Менеджер пакетов:** uv (современная и быстрая альтернатива pip/poetry).
- **Распознавание речи (STT):** Groq API (Модель Whisper Large V3).
- **Логика преподавателя (LLM):** Google GenAI API (Модель Gemini 2.5 Flash) с возможностью быстрого переключения на Llama 3.3 через конфигурационный файл.
- **База данных сессий:** Redis (персистентное хранение истории контекста, автоматическое удаление неактивных сессий через 48 часов).
- **Валидация данных:** Pydantic V2 + Pydantic Settings.
- **Контейнеризация:** Docker (Multi-stage сборка на базе Alpine Linux).

## Пошаговое руководство по получению API-ключей

### 1. Telegram Bot Token
1. Откройте Telegram и найдите официального бота @BotFather.
2. Отправьте команду `/newbot`.
3. Укажите видимое имя бота, а затем уникальный юзернейм, заканчивающийся на `_bot`.
4. Скопируйте сгенерированный API Token (формата `123456789:ABCdef...`).

### 2. Google Gemini API Key
1. Перейдите на платформу Google AI Studio (https://google.com).
2. Авторизуйтесь под вашим Google-аккаунтом.
3. Нажмите кнопку "Get API key" в верхнем левом углу.
4. Нажмите "Create API key", выберите проект и скопируйте созданный ключ.

### 3. Groq API Key
1. Перейдите в панель управления Groq Cloud Console (https://groq.com).
2. Создайте аккаунт или авторизуйтесь.
3. В левом навигационном меню перейдите в раздел "API Keys".
4. Нажмите "Create API Key", введите название ключа и скопируйте его значение.

## Локальная разработка и запуск в Docker

1. Склонируйте репозиторий с проектом.
2. Создайте файл `.env` в корневом каталоге на основе `.env.example`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_телеграм
GROQ_API_KEY=ваш_ключ_groq
GEMINI_API_KEY=ваш_ключ_gemini
REDIS_URL=redis://redis:6379/0
```
3. Для локального запуска базы данных и бота разверните окружение с помощью Docker:
```bash
# Сборка и запуск контейнеров в фоновом режиме
docker-compose up --build -d
```
*(Если используется чистый Dockerfile без compose, убедитесь, что в переменной REDIS_URL указан доступный адрес хоста).*

## Развертывание в облаке Render.com

Платформа Render позволяет бесплатно или по минимальной цене развернуть инфраструктуру приложения из Docker-контейнера.

### Шаг 1. Создание базы данных Redis
1. Войдите в панель управления Render (https://render.com/).
2. Нажмите кнопку "New" -> "Key Value" (или Redis в зависимости от текущего интерфейса).
3. Укажите имя базы данных (например, `eng-bot-cache`).
4. Нажмите "Create Key Value". После создания скопируйте значение строки **Redis Connection String** (она начинается с `rediss://`).

### Шаг 2. Создание сервиса бота
1. В панели Render нажмите "New" -> "Background Worker" (данный тип сервиса предназначен для долгоживущих процессов, работающих по схеме long polling без вебхуков).
2. Подключите ваш GitHub репозиторий с кодом бота.
3. В настройках деплоя укажите:
   - **Runtime:** `Docker`
4. Перейдите во вкладку **Environment** сервиса и добавьте следующие переменные:
   - `TELEGRAM_BOT_TOKEN` = (значение из BotFather)
   - `GROQ_API_KEY` = (значение из Groq Console)
   - `GEMINI_API_KEY` = (значение из Google AI Studio)
   - `REDIS_URL` = (вставьте скопированную строку Connection String из Шага 1)
5. Нажмите "Deploy". Бот соберется из Dockerfile и запустится в облаке.

### Шаг 3. Настройка автоматического CI/CD
1. В настройках созданного Background Worker найдите строку **Deploy Hook**. Скопируйте уникальный URL.
2. Перейдите в ваш GitHub репозиторий -> Settings -> Secrets and variables -> Actions.
3. Создайте новый секрет с именем `RENDER_DEPLOY_WEBHOOK_URL` и вставьте скопированный URL-адрес в качестве значения.
4. Теперь при каждом выполнении `git push` в ветку `main` Render будет автоматически обновлять код приложения на сервере.
